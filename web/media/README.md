# Hover videos for the start menu

Put the two short clips here, with exactly these names:

| File | Plays on |
|---|---|
| `f1.mp4` | the **F1** button |
| `f1-25.mp4` | the **F1 25** button |

You can also add `f1.webm` and `f1-25.webm` (smaller files); the page uses them when they're there.

Good clips for this:
- 3 to 8 seconds, made to loop smoothly (it repeats while the pointer is on the button)
- landscape, about 1280 × 720, under about 5 MB
- no sound needed (it plays muted)

The text sits on the left of the button, over a dark fade, so the action works best on the right side of the frame.
Until a file is here, the button simply looks as it always did.
